# Salahutu Mountain Hiking Routes Map / *Peta Jalur Pendakian Pegunungan Salahutu*

Simple interactive web page for selecting and downloading hiking route maps for Mount Salahutu. Users can select “Ascent via” and “Descent via” routes, then download a GPX file for the chosen track.

*Halaman web interaktif sederhana untuk memilih dan mengunduh peta jalur pendakian Gunung Salahutu. Pengguna dapat memilih rute “Naik via” dan “Turun via”, lalu mengunduh file GPX sesuai jalur yang dipilih.*

---

## Data & Mapping / *Data & Pemetaan*

Route data was collected using a **Suunto Baro 9** GPS watch, ensuring accurate elevation and track recording in mountainous terrain. The final map was processed and created using **QGIS** for spatial analysis and visualization.

*Data jalur dikumpulkan menggunakan jam GPS **Suunto Baro 9**, untuk memastikan akurasi elevasi dan rekaman lintasan di medan pegunungan. Peta akhir diproses dan dibuat menggunakan **QGIS** untuk analisis dan visualisasi spasial.*
